Viva-ready notes

Why Branch & Bound wins

  • Backtracking visits feasible take/skip paths depth-first and cuts only overweight paths.
  • Branch & Bound computes an optimistic fractional-knapsack upper bound. If it cannot beat the current best value, that whole subtree is discarded.
  • Both are exact 0/1 solvers: no dynamic programming table is used.
  • Worst case for both remains O(2ⁿ) time. Backtracking uses O(n) call-stack space; best-first Branch & Bound can hold O(2ⁿ) live nodes.
