Algorithm Mechanics

How the algorithms behave

Backtracking

Explores the decision tree depth-first. It prunes a branch when the current load violates the vehicle capacity.

Branch & Bound

Uses an optimistic upper bound to estimate the best possible utility from a branch. If that bound cannot beat the current best solution, the branch is discarded.

Theoretical Guarantee: Both algorithms still guarantee the exact optimal 0/1 Knapsack solution. Branch & Bound can explore fewer nodes when its bound is effective, although calculating bounds introduces additional overhead.

Operational Context

Why this matters

In emergency logistics, vehicle capacity is limited while supplies have different levels of importance. An optimization algorithm can help determine which supplies should be transported when carrying everything is impossible.

  • Limited vehicle capacity: Physical payload constraints make overloading catastrophic.
  • Different supply priorities: Essential survival kits and medicines must take precedence over lower-utility items.
  • Need for an exact optimal combination: Heuristics can leave critical life-saving utility behind.
  • Computational cost of searching combinations: Pruning unpromising combinations in 2ⁿ state space is essential for fast decision support.

Viva-Ready Notes

Algorithm Analysis & Bounds

  • Backtracking visits feasible take/skip paths depth-first and prunes as soon as the accumulated load exceeds vehicle capacity.
  • Branch & Bound computes an optimistic fractional-knapsack upper bound. If that bound cannot beat the current best utility, that entire subtree is discarded immediately.
  • Exact Solvers: Both are exact 0/1 solvers — no dynamic programming table or approximation is used.
  • Complexity: Worst-case time is O(2ⁿ). Backtracking requires O(n) call-stack space; best-first Branch & Bound priority queue can store up to O(2ⁿ) active states.
